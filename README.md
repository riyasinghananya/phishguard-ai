# AI Powered Phishing Detection System

AI-based cybersecurity project developed using Django, Python, and Machine Learning.

## Features
- Phishing website detection
- Safe vs dangerous URL prediction
- Threat score generation
- Fake URL detection
- HTTPS security checking
- TinyURL detection
- AI chatbot support

## Technologies Used
- Python
- Django
- Machine Learning
- HTML/CSS
